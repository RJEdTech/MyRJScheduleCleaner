MyRJ Schedule Cleaner
Import your teaching schedule without looking busy all day

Import your MyRJ schedule into Outlook the right way — your classes show as busy, and the all-day Red and White day markers stop blocking your whole day. This page walks you through it one step at a time: each step is a single thing to do, with a picture, and the next one opens when you're done. You can't break anything here — it only makes a tidy copy of a file on your own computer, it can't change MyRJ or anyone else's calendar, and nothing is uploaded.

Not “School Calendars”
Further down that page is a separate School Calendars section. Those are the whole school's calendars — roughly 1,700 events, nearly all of them other people's games, practices, and meetings. Why can't this page just download the file for me?

Because that link is effectively a password to your schedule. Anyone holding it can read your whole calendar — there's no sign-in on it.

For a page like this one to fetch the file directly, MyRJ would have to permit it, and it doesn't. The usual workaround is to bounce the request through somebody else's server, and that would mean a hundred teachers' schedule links passing through a machine nobody here controls. That's not a trade worth making to save you one click, so the download stays between you, MyRJ and your own browser.

It also means this page never sees your link or your calendar. Once the file is on your computer, everything below happens inside this browser tab, with the network unplugged if you like.

Then, in Outlook: New Outlook & Outlook on the web

  1. Add calendar → Upload from file
  2. Browse to the file you just downloaded
  3. Set the Add to dropdown — the box under the file name — to your main calendar, the one Outlook made for you. Not a new one, and not a calendar you added yourself.

In classic Outlook the same job lives under File → Open & Export → Import/Export → Import an iCalendar (.ics) file, and when it asks, choose Import rather than Open as New.

Why my main calendar, and undoing it later
Why your main calendar, and what it costs you

Putting this in a calendar of its own is tidier and far easier to delete later — but a calendar you add yourself doesn't reliably tell colleagues you're busy, and being visibly busy is the entire reason for importing. So: main calendar, and accept that removing it later takes a few more steps than deleting a whole calendar would.

Those steps are written out in Removing a past import, they work, and the labels this tool adds are what make them quick. If you'd genuinely rather have easy deletion than busy time — some people only want the schedule visible on their phone — then a separate calendar is the better choice for you, and nothing else on this page changes.

In New Outlook, imported events look gray until you pick a color — once. New Outlook colors each event by its first label, and that label has no color in your mailbox yet. Set it one time and every matching event changes at once.

  1. Click the gear icon (Settings, top-right).
  2. Go to Accounts → Categories.
  3. Find MyRJ Import in the list and click its pencil icon → pick a color → Save. Don’t see it in the list? New Outlook often hides categories that arrived by import — click + Create new, name it exactly MyRJ Import (copy the spelling from the category chip on any imported event), pick a color and Save. Outlook matches by name, so every event picks up the color at once. Chose a color per class? Do the same for each course name plus Red Day, White Day and School Calendar.
  4. Every event with that label recolors instantly. Leave the dated MyRJ Import 2026-08 row alone — it's only for finding this batch later.

These label names don't change semester to semester, so this is a one-time job — next year's import arrives already colored.

Why gray? And what classic Outlook does differently
Not the colours you expected? That's the labels, not a bad import

The two Outlooks colour events differently, and the same imported file looks different in each:

  • Classic Outlook — everything comes in the calendar's own colour, the same as the rest of that calendar. The labels are still there doing their job, they just don't change how anything looks.
  • New Outlook and the web — an event takes its colour from its first label instead. So your imported schedule can arrive in colours you didn't choose, or in grey where the label has no colour yet.

Nothing is wrong with the file either way. If you want to decide the colours yourself: Settings → Accounts → Categories, find the label, click the edit icon and pick a colour. Every event carrying it changes at once. In classic Outlook the same list is under Categorize → All Categories on any event.

Colour the labels listed above — the ones this run created. If you chose one label for everything that's a single MyRJ Import; if you chose a label per class it's one per course plus Red Day, White Day and School Calendar. Leave the dated label alone: it exists for finding and deleting this batch later, not for colour.

These names don't change from semester to semester, so this is genuinely one-time. Next year's import lands already coloured.

Things that look wrong but aren't

A day with no Red or White marker. MyRJ only publishes the day-type marker on days you have something scheduled. If you have a free Tuesday, that Tuesday arrives bare. Nothing was lost in the cleaning — it was never in the file.

How far ahead it reaches varies. The feed usually covers about the last two months and the next twelve — but sometimes the whole year comes through, and sometimes it stops short (it has ended around April before). Nothing was lost in the cleaning either way. If you notice it only reaches part-way through the year, re-run this to pull a fresh copy.

Colours you didn't pick, or grey. That's new Outlook colouring by label, explained just above. In classic Outlook you'll see none of this — everything arrives in the calendar's own colour.

The same import looking different on two machines. Expected, for the same reason. It's the same events either way.

What you imported is a snapshot — it won't update itself. Add a live subscription so schedule changes still reach you. Takes about ten seconds, and you already have the link.

  1. Add calendar → Subscribe from web.
  2. Paste the same link from Step 1 (reopen Step 1 above to copy it again if you need it).
  3. Name it something like MyRJ (live) → Import.

The import is what makes you look busy to colleagues. The subscription is what keeps you right. When the two disagree, believe the subscription — though on a weather-delay morning it can lag a few hours, so check MyRJ itself that day.

Removing a past import

Reference — always here

You'll need this when your schedule changes, at the start of a new semester, or if you imported twice by accident. Outlook has no “undo this import” button — but you never have to hunt through months of calendar grid either.

First: did you import into a calendar of its own?
If you created a separate calendar for this (something like “MyRJ Schedule”), you're done in two clicks: right-click that calendar in the left-hand list → Delete Calendar. Everything in it goes at once and nothing of yours is touched.

If you followed Step 4 and imported into your main calendar, that was the right call — it's what makes you look busy to colleagues — and the steps below are how you undo it. They're longer, but the labels this tool adds make it a single selection rather than hundreds of clicks.
Deleting from your main calendar Classic Outlook

Outlook's calendar can be turned into a sortable table, which makes this one selection instead of hundreds of clicks. This needs classic Outlook — new Outlook and the web version have no List view. If you're in new Outlook, switch the New Outlook toggle off (top right) before you start; there's more on that at the bottom of this section.

  1. Open Calendar in Outlook
  2. View tab → Change View → List or Active — either turns the calendar into a flat, sortable tableThe step most people have never used. Whichever you pick, make sure the Categories column is showing — that’s where MyRJ Import 2026-08 and podium appear, and it’s how you’ll find the batch. If the column isn’t there, right-click any column heading → Field Chooser → drag Categories onto the row. Then sort or group by that column and you can select the whole batch at once.
  3. Find the batch using one of the three handles below — they all gather the imported events into one contiguous block
  4. Click the first event in the block, then Shift+click the last
  5. Read down the Subject column and confirm it's all class blocks and Red/White day markers
  6. Press Delete
  7. View → Change View → Calendar to go back to normal
Three ways to find the batch
  • The import labels Try firstEvery event this tool writes carries MyRJ Import plus a dated MyRJ Import YYYY-MM. Searching category:"MyRJ Import" with the scope set to Current Folder finds every import that still carries the label (an older one that lost it won't show — that's what Podium below is for); the dated one narrows it to a single batch, and its month answers “when did I import this?” Sorting the Categories column groups them either way.
  • The moment they arrivedWorks even when there's no label. Right-click any column heading → Field Chooser → drag Created onto the header row, then click it to sort. Every event from a single import shares one timestamp down to the minute, so the whole batch sits together — and that timestamp is the import date, recovered.
  • MyRJ's own categories Most completeSchedule-feed events arrive tagged Podium and Events, and — unlike the MyRJ Import label — these are never lost, so every import you've ever run carries them. That makes the Podium group the surest way to clear out old imports in one pass: select it and you catch this batch and any older ones, including early imports that dropped the MyRJ Import label. Nothing you create yourself is tagged Podium, so the group holds only MyRJ imports — still, glance down it once before you delete.
Imported before August 2026? The label may be missing
Earlier versions of this tool could lose the MyRJ Import label on the way into Outlook, on events whose category list was already long. If you don't see it, that's why — use the Created column instead, which works regardless. Files cleaned here now keep the label reliably.
Check the selection before you press Delete
If a real appointment of yours has crept into the selection, Ctrl+click it to deselect. Deleted calendar items go to Deleted Items and can be dragged back, and Ctrl+Z undoes the delete if you catch it immediately — but it's easier to catch here than to fish items out afterwards.
If you don't see “Change View”

You're in new Outlook or Outlook on the web, which has no List view. Switch the New Outlook toggle off (top right) to get the classic version, where all of the above works — it's the same mailbox and the same events, just a different window onto them. Switch it back afterwards if you prefer the new one.

If classic Outlook isn't available to you at all, deleting an import from a main calendar by hand isn't realistic, and the honest advice changes: put your next import in a calendar of its own so removing it is two clicks. You'll give up the busy-blocking that makes colleagues stop booking over your classes — that's the trade — but you'll still have your schedule on your phone and on screen, and the live subscription from Step 5 keeps it accurate.

Then re-import

Once the old set is gone, start again at Step 1: download a fresh copy of the feed, clean it here, and import. The new batch gets its own dated label, so next time this takes about a minute.
